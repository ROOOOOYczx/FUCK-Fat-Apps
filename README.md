# FUCK Fat Apps

一个面向 LSPosed 的应用净化模块，当前第一阶段适配高德地图 `com.autonavi.minimap`。

## 当前功能

- 模块总开关。
- 跳过高德启动页广告：拦截启动页生命周期中的展示判断和展示调用。
- 隐藏高德 Banner/推广横幅：针对 `DBanner` 与 `BannerView`，并对其可见性做兜底处理。
- Banner 初始化实验开关：阻止已识别的 Banner 管理器初始化/拉取方法，默认关闭。
- 精简首页内容：保留地图、搜索栏、15 个工具、路线卡片以及家/单位/常去地点；移除天气及其下方内容，默认关闭。
- 移除 AI 长按对话入口：隐藏底部中间的“长按说话”按钮，默认关闭。
- 精简“我的”页：保留个人信息、足迹、语音包/车标、订单及车辆服务等上方板块；隐藏“借钱”入口，并从“达人任务”开始移除其后的页面内容，默认关闭。

Hook 只在高德地图进程中安装，不会影响其它应用。版本差异较大时，实验开关可能需要关闭。

## 安装和启用

1. 使用 Android Studio 或命令行执行 `gradlew.bat assembleDebug`。
2. 将 `app/build/outputs/apk/debug/app-debug.apk` 安装到 root 设备。
3. 在 LSPosed 中启用模块，并只勾选高德地图作用域。
4. 修改开关后强制停止高德地图，再重新打开。

## 调试

```powershell
adb logcat -s LSPosed-Bridge
```

模块日志前缀为 `[FUCK Fat Apps]`。当前设备上的高德版本是 `16.22.0.2018`，提供的静态分析 APK 是 `16.23.0.2005`；后续真机回归时应分别验证启动页、首页和路线页面。
